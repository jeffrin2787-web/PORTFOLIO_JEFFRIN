# Jeffrin E — Portfolio

A responsive, interactive portfolio built with plain **HTML, CSS and JavaScript**.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive styling, animations and dark mode
- `script.js` — navigation, typing effect, scroll reveal, theme switcher and contact form
- `assets/profile-placeholder.svg` — temporary profile image

## Add your photo

When you upload your real profile photo, save it as:

`assets/profile.jpg`

Then open `index.html` and change:

```html
<img src="assets/profile-placeholder.svg" ...>
```

to:

```html
<img src="assets/profile.jpg" ...>
```

The portrait frame is intentionally tall/portrait-oriented so a professional head-and-shoulders photo will fit well.

## Customize before GitHub

1. Replace the placeholder photo.
2. Add your GitHub and LinkedIn URLs in `index.html` where the social links currently use `href="#"`.
3. Add GitHub repository links to the project cards if available.
4. Review the email/phone details before making the repository public.
5. Open `index.html` locally to preview.

## GitHub Pages

Create a GitHub repository, upload all files while keeping the `assets` folder, then enable **Settings → Pages → Deploy from branch**.

No framework or build step is required.
